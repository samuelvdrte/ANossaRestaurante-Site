# 🍽️ A NOSSA - Sistema de Gestão e Cardápio Digital para Restaurante

> Um aplicativo web moderno desenvolvido para otimizar o atendimento de restaurantes, permitindo aos clientes navegar por um cardápio digital interativo e enviar pedidos diretamente via WhatsApp, acompanhado de um painel administrativo integrado.

---

## 🚀 Sobre o Projeto

O **A NOSSA** foi concebido para resolver necessidades reais de estabelecimentos gastronómicos, unindo uma interface limpa e intuitiva para os clientes com ferramentas práticas de gestão para os administradores. O sistema foca na acessibilidade, usabilidade em dispositivos móveis (Mobile-first) e agilidade na comunicação de pedidos.

---

## ✨ Principais Funcionalidades

* 📱 **Cardápio Digital Interativo**: Visualização de produtos organizados por categorias (Pratos Principais, Bebidas, Sobremesas, etc.) com fotos, descrições e preços detalhados.
* 🛒 **Carrinho de Compras Inteligente**: Adição, remoção e alteração de quantidades de itens, incluindo um campo dedicado para observações especiais nos pedidos.
* 💬 **Integração com WhatsApp**: Formatação automática dos itens do carrinho e envio direto do pedido formatado para o atendimento do restaurante.
* ⚙️ **Painel Administrativo (Dashboard)**: Área restrita para gerir o catálogo de produtos (adicionar, remover e atualizar preços e imagens de forma dinâmica).
* ♿ **Modo de Alto Contraste**: Recurso de acessibilidade implementado para garantir legibilidade e conformidade com diretrizes inclusivas.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando as seguintes tecnologias e ferramentas:

* **HTML5 / CSS3 / JavaScript (ES6+)**: Estruturação, estilização avançada e lógica da aplicação.
* **Bootstrap**: Framework CSS para garantir um design responsivo e componentes modernos.
* **Estrutura de Dados / JSON**: Armazenamento e manipulação local de produtos, categorias e preços.
* **Git & GitHub**: Controlo de versões e hospedagem do projeto.
* **Netlify / GitHub Pages**: Plataformas utilizadas para deploy e publicação da aplicação online.
